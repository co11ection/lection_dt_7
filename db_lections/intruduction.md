==================== База данных ===========================
База данных - это хранилище где хранится определенная информация
СУБД - система управления базами данных (MySQL, PostgreSQL, MongoDB)
SQL (Structured Query Language) - язык для работы с базами данными
c помощью SQL можем:
    1)Создать (базу данных, таблицу, данные добавить)
    2)Обновить (таблицу, обновить данные)
    3) Просмотреть (базу данных, таблицы, данные)
    4) удалить (базу данных, таблицы, данные)

================= Типы данных =====================
числовые - INT, BIGINT, DECIMAL, FLOAT (age - INT, salary - DECIMAL)
---------------------------------------------------------------------------------
строчные - CHAR(255 символов ограничении) , VARCHAR(255 символов ограничении), TEXT(бесконечно символов ограничении) 
CHAR(50) = "hello world                      " - если все символы не использовать заполниьт пробелами
VARCHAR = "hello world" - если не использовать все символы он лишнее просто вырезает
name - VARCHAR(50)
description - Text
---------------------------------------------------------------------------
булевые(логический тип) - BOOLEAN - true/false
is_admin - BOOLEAN = true/false
--------------------------------------------------------------------------
дата и время - DATE(дата), TIME(время), DATETIME(дата и время)
birth_day - DATE
created_at - DATETIME
===============================================================
---------------- SQL - ОПЕРАТОРЫ и классы команд ----------------------------

Все команды писать капсом(большими буквами)
=================================================================
DDL - DATA definition language
Команды для создания и изменения структуры базы данных
Команды:
CREATE -> Создать
ALTER -> Изменить
DROP -> Удалить
RENAME -> Переименовать
TRUNCATE -> очистки таблицы
==================================================================
DML - DATA MANIPULATION LANGUAGE
Команды для работы с данными

INSERT -> добавить данные
UPDATE -> обновить(изменить) данные
DELETE -> Удалить данные
===================================================================
DQL - DATA QUERY LANGUAGE
Команды для получения данных 

SELECT -> выборка данных (получение)
==================================================================
DCL - DATA CONTROL LANGUAGE
Команды для управления правами(доступами)
GRANT - выдать права
REVOKE - забираем права

==================================================================
TCL - Transaction control language
Команда для управления транзакциями (все, либо ничего)

COMMIT - сохранения изменений
ROLLBACK - отмена изменений
SAVEPOINT - точка сохранения
==================================================================

# Открыть
    Для винды открываем MYSQL COMMAND LINE CLIENT 
    На маке(линукс) - mysql -u <username>/<root>  -p
# Закрыть
    \q

# Посмотреть какие базы данных есть:
    SHOW DATABASES;

# Создать базу данных
    CREATE DATABASE <name of db>;

# Подключение к базе данных (Использование)
    USE <name of db>;

# Удаление базы данных
    DROP DATABASE <name of db>;

# Создание таблицы
    CREATE TABLE <name of table> ( 
    -> id INT PRIMARY KEY,
    -> name VARCHAR(100),
    -> age INT,
    -> email VARCHAR(100)
    -> );

# Добавление данных(записей) в таблицу
    INSERT INTO <name of table> VALUE (1, 'Asan', 22, 'asan@gmail.com');

# Получение данных(записей) с таблицы
    SELECT * FROM <name of table>;
